# Трекер самолётов в воздушном пространстве
*по выбранным странам через API (OpenSky и Nominatim) с интеграцией PostgreSQL*

## Описание
Python-приложение (консольный интерфейс + веб-версия) для получения и анализа данных о самолётах в воздушном пространстве выбранных стран/городов.

Программа:
- определяет координаты стран через Nominatim API или использует фиксированные данные;
- получает актуальный список самолётов в воздухе через OpenSky API;
- преобразует сырые данные в объекты `Aeroplane`;
- записывает все данные в базу PostgreSQL;
- выводит отчёты в консоли и на сайте.

## Возможности (Консоль)
- загрузка самолётов по стране или городу из списка, а также ручной ввод;
- **Интеграция базы данных**: автоматическое создание таблиц и связей в PostgreSQL;
- **Универсальное меню аналитики**: вызывается кнопкой `"-"` на главном экране;
- быстрый расчет статистики средствами базы данных:
 - точный подсчет количества бортов по всем указанным регионам;
 - вычисление средней скорости всех самолетов в небе;
 - мгновенный вывод самолетов, летящих быстрее средней скорости;
 - поиск бортов по ключевым символам в их позывном;
- резервные координаты для стран и городов;
- фильтры, ТОП-лидеры, ТОП-N по высоте/скорости и статистика (в воздухе/на земле/SPI);
- логирование по модулям.

## Установка
1. Клонируйте репозиторий:  
https://github.com/Yulianna-Aleeva/sky-tracker.git
2. Установите зависимости:  
```bash
poetry install
```

## Настройка
### 1. Переменные окружения (`.env`)
Откройте шаблон [.env.example](.env.example), добавьте свои данные и переименуйте файл в `.env` (в PyCharm это можно сделать клавишами `Shift + F6`):
```text
# Путь к JSON-файлу с данными о самолётах
FILE_PATH=___ваш путь к файлу___

# Ваши данные от OpenSky Network
# https://opensky-network.org/
OPENSKY_USER=___ваш логин___
OPENSKY_PASS=___ваш ключ___
```

### 2. Настройка базы данных (`database.ini`)
Откройте шаблон [database.ini.example](database.ini.example), добавьте свои данные подключения и переименуйте файл в `database.ini` (`Shift + F6`):
```ini
[postgresql]
host=localhost
user=postgres

# Вставьте ниже свой пароль от pgAdmin/PostgreSQL
password=___ваш пароль___

port=5432
dbname=sky_tracker_db
```
*(Файлы `.env` и `database.ini` скрыты в [.gitignore](.gitignore) для безопасности).*

В [user_settings.json](user_settings.json) находятся:
- `geo_url` — Nominatim API для определения координат;
- `sky_url` — OpenSky API для получения самолётов;
- `user_countries` — список стран и городов в меню;
- `country_coordinates` — резервные координаты `[min_lat, max_lat, min_lon, max_lon]`.

## Запуск приложения
`python main.py`

## Веб-версия
Проект имеет веб-интерфейс на Flask с модульной архитектурой (`Blueprint`).

### Возможности:
- выбор страны из списка или свой ввод;
- список самолётов с интерактивной таблицей;
- **Глобальный SQL-дашборд**: отдельная страница аналитики базы данных PostgreSQL;
- вывод средней скорости, количества воздушных судов по регионам и топ-10 самых быстрых бортов прямиком из базы данных;
- дизайн кнопок навигации, встроенный в общий каркас страниц.

### Запуск веб-версии:
`python app.py`  
Открыть в браузере:  
http://127.0.0.1:5000
