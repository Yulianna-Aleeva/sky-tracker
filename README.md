# Трекер самолётов в воздушном пространстве
*по выбранным странам через API (OpenSky и Nominatim)*


## Описание
Консольное Python-приложение для получения данных о самолётах в воздушном пространстве выбранной страны.

Программа:
- определяет координаты страны через Nominatim API;
- при недоступности гео-API использует сохранённые координаты из настроек;
- получает список самолётов через OpenSky API;
- преобразует сырые данные в объекты `Aeroplane`;
- сохраняет данные в JSON;
- показывает таблицу, сводку, статистику и топы.


## Возможности
- загрузка самолётов по стране или городу из списка;
- также имеется ручной ввод страны для анализа;
- резервные координаты для стран и городов;
- фильтр по стране регистрации;
- ТОП-3 лидеров: быстрый / высокий / крутой;
- ТОП-N по высоте;
- ТОП-N по скорости;
- статистика:
  - в воздухе;
  - на земле;
  - спецрейсы (SPI);
- сводка по странам вылета;
- сохранение данных в JSON;
- логирование по модулям.

```bash
poetry install
```


## Настройка
Файл `.env` уже входит в проект.

В `user_settings.json` находятся:
- `geo_url` — Nominatim API для определения координат;
- `sky_url` — OpenSky API для получения самолётов;
- `user_countries` — список стран и городов в меню;
- `country_coordinates` — резервные координаты `[min_lat, max_lat, min_lon, max_lon]`.

Если Nominatim недоступен, программа автоматически использует фиксированные координаты из `user_settings.json`.
